# OMI China Coal-Plant SO2 Pipeline

Live data dashboard for Yaonan Liu's RA project (Prof. Steven Chen, University of Windsor).

## What this is

Replicates Steven Chen (2021) SSRN paper #3963306 methodology for evaluating Power Sector Emissions under China's Regional Carbon ETS Pilots, updated daily to current data.

## How to view

Open `index.html` in any browser, or visit the GitHub Pages URL.

## Auto-update

Yaonan's machine runs the OMI extraction pipeline daily at 02:30 AM and pushes results here.

## Files

- `index.html` — the dashboard (auto-refreshes every 5 min)
- `chart_daily_last60days.png` — daily SO2 trend (last 60 days)
- `chart_treated_vs_control_quarterly.png` — quarterly trend (2019-2026)
- `recent_30days_daily.csv` — last 30 days daily plant-level data
- `quarterly_by_date.csv` — full quarterly data 2019-2026
- `plants_china_filtered_v2.xlsx` — the 215 plant sample with vs-Steven-2021 comparison
